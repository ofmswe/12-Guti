This is a traditional12 Guti Game. Developed by Java with Javafx.

Game rule:
• The game is played on a 5×5 board with 25 positions.
• Each player starts with 12 pieces.
• Player 1 uses Red pieces.
• Player 2 uses Blue pieces.

Moves:
• Walk – Move a piece to an adjacent empty position.
• Jump – Jump over an opponent's piece to capture it.
• Chain Jump – After a successful jump, if the same piece can make another jump, the player may continue jumping with that piece in the same turn.

Winning Conditions:
A player wins by:
• Capturing all of the opponent's pieces, or
• Blocking the opponent so that they have no legal moves remaining.
